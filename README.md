# MDT Loop · ENT — Beta

תקשורת במעגל סגור בין הדיסציפלינות בצוות המולטידיסציפלינרי לגידולי ראש-צוואר,
מחלקת אף אוזן גרון וכירורגיית ראש-צוואר, מרכז רפואי מאיר · שירותי בריאות כללית.
אפליקציית Next.js סטטית — בלי שרת, בלי מסד נתונים ובלי משתני סביבה.

## העלאה ל-GitHub

**קודם** יוצרים ב-GitHub מאגר **ריק** בשם `MDT-LOOP-ENT-MEIR` תחת החשבון
`avivd888-sudo` — **בלי** לסמן README, בלי .gitignore ובלי רישיון. אם מסמנים
משהו מהם, ה-push הראשון ייכשל.

```bash

git branch -M main
git remote add origin https://github.com/avivd888-sudo/MDT-LOOP-ENT-MEIR.git
git push -u origin main
```

## חיבור ל-Vercel

1. ב-Vercel: **Add New… → Project**
2. **Import** את המאגר `MDT-LOOP-ENT-MEIR`
3. Framework Preset: **Next.js** (נבחר אוטומטית)
4. **אין** צורך במשתני סביבה — משאירים את Environment Variables ריק
5. **Deploy**

הכתובת שתתקבל תיראה כך:

```
https://mdt-loop-ent-meir.vercel.app/
```

שם המארח הזה גלובלי ב-Vercel. אם הוא כבר תפוס, Vercel יוסיף סיומת — אפשר לשנות
את שם הפרויקט ב-Settings ולתפוס כתובת אחרת.

## עדכון הגרסה

```bash
git add .
git commit -m "מה השתנה"
git push
```

Vercel בונה ומפרסם אוטומטית בכל push ל-`main`.

## הרצה מקומית לפני שמעלים

```bash
npm install
npm run build      # יוצר out/
node preview.mjs   # מגיש את out/ בכתובת http://localhost:4173
```

בדיקת המסלולים המלאה (עברית ואנגלית):

```bash
node verify.mjs    # דורש preview.mjs רץ ברקע
```
